## 1. 执行摘要

### 1.1 平台定位

**SAAS New** 是一款面向广告主（Advertiser）和渠道商（Publisher）的**下一代联盟营销管理平台**，通过**智能风险控制**和**双端结算确认体系**，帮助客户：

- ✅ **降低扣量损失**：多维度风险控制，在流量上游阻断欺诈
- ✅ **杜绝财务漏洞**：双端结算确认，100% 避免亏本倒挂垫资风险
- ✅ **提升运营效率**：自动化财务对账，减少 80% 人工操作
- ✅ **实时数据透明**：Postback 日志全链路追踪，数据零丢失

### 1.2 核心价值

| 价值维度 | 传统平台 | SAAS New 平台 | 提升效果 |
|---------|---------|--------------|---------|
| **风险控制** | 人工审核，滞后发现 | 实时监控，自动预警 | 损失降低 **60%+** |
| **财务对账** | 单端确认，易出错 | 双端确认，自动匹配 | 错误率降低 **95%+** |
| **结算周期** | 月结，资金压力大 | 灵活结算，实时对账 | 资金周转提升 **3x** |
| **数据透明度** | 黑盒操作 | 全链路追踪 | 信任度提升 **100%** |

## 2. 平台概述

## 3. 技术壁垒：智能风险控制体系

### 3.1 行业痛点

传统联盟营销平台面临以下风险：

1. **欺诈流量**：Bot 流量、设备农场、点击劫持等欺诈手段，导致广告主损失严重
2. **扣量损失**：三方数据不一致，广告主扣量，平台承担损失
3. **滞后发现**：人工审核滞后，欺诈行为已经发生，损失无法挽回
4. **规则僵化**：固定规则无法应对新型欺诈手段，漏检率高

### 3.2 SAAS New 的解决方案

#### 3.2.1 多维度风险控制体系

SAAS New 通过**多维度风险控制体系**，在流量上游阻断欺诈，将联盟平台的综合扣量损失控制在行业最低水平。

**核心能力**：

| 风险控制维度 | 实现机制 | 效果 |
|------------|---------|------|
| **Fraud 检测** | 实时监测异常流量模式（如 Bot 特征、设备农场） | 阻断 **90%+** 欺诈流量 |
| **CTIT 监控** | 监控 Click-to-Install Time（点击到安装时间） | 识别 **80%+** 激励流量 |
| **Post-Attribution 追踪** | 追踪后归因行为，识别异常转化 | 降低 **50%+** 无效转化 |
| **转化率异常检测** | 监测 Publisher 转化率异常波动 | 提前 **7 天** 预警风险 |

**技术实现**：

```javascript
// 风险控制规则配置（示例）
{
  "rule_name": "CTIT 异常预警",
  "condition": "ctit < 10",  // Click-to-Install Time < 10 秒
  "action": "auto_scrub",    // 自动扣除相关转化
  "notify": true             // 发送预警通知
}
```

#### 3.2.2 自动化预警规则系统

SAAS New 提供**可配置的自动化预警规则系统**，让运营人员根据具体业务需求，灵活配置风险阈值。

**核心功能**：

1. **预警规则配置**：
   - 支持多种触发条件（CTIT、转化率、Revenue 异常等）
   - 支持多种执行动作（自动扣除、发送通知、暂停 Campaign 等）
   - 支持规则优先级配置

2. **实时预警日志**：
   - 所有预警事件自动记录
   - 支持单个/批量处理
   - 支持处理备注和原因分类

3. **预警处理流程**：
   ```
   触发预警 → 记录日志 → 自动执行动作（可选） → 通知运营人员 → 人工审核（可选） → 处理完成
   ```

**业务价值**：

- ✅ **提前预警**：在损失发生前，提前 7-14 天预警风险
- ✅ **自动处理**：简单风险自动处理，减少 80% 人工操作
- ✅ **可追溯**：所有预警和处理记录可追溯，便于审计和优化

#### 3.2.3 流量质量实时监控

SAAS New 提供**流量质量实时监控**，让广告主和平台实时了解流量质量。

**核心功能**：

## 4. 财务护城河：双端结算确认体系

### 4.1 行业痛点

传统联盟营销平台面临以下财务风险：

1. **三方跑数延迟**：广告主和平台的转化数据不同步，导致结算延迟
2. **丢单漏单**：数据丢失或重复，导致结算错误
3. **亏本倒挂垫资**：平台先垫资给 Publisher，但广告主拒绝结算，导致平台亏损
4. **人工对账效率低**：人工对账耗时耗力，错误率高

### 4.2 SAAS New 的解决方案

#### 4.2.1 双端结算确认体系（AM/PM Double Check）

SAAS New 通过**双端结算确认体系**（Advertiser Confirmed → Publisher Confirmed），100% 杜绝因三方跑数延迟、丢单导致的联盟亏本倒挂垫资风险。

**核心机制**：

```
步骤 1：Advertiser 确认（AM Confirmed）
  - 广告主确认转化数据
  - 状态：A Status = Confirmed
  - 记录：a_confirmed_by、a_confirmed_at

步骤 2：Publisher 确认（PM Confirmed）
  - 渠道商确认转化数据
  - 状态：P Status = Confirmed
  - 记录：p_confirmed_by、p_confirmed_at

步骤 3：财务对账
  - 只有双端确认的数据，才进入财务对账
  - 未确认的数据，暂存在"待确认"状态
  - 支持批量操作和快速编辑
```

**技术实现**（基于真实代码）：

```javascript
// Finance.jsx - 双端结算确认机制
const mapApiRow = (item, idx) => {
  return {
    // ... 其他字段
    aStatus: item.advertiser_status === 1 ? 'confirmed' : 'pending',
    pStatus: item.publisher_status === 1 ? 'confirmed' : 'pending',
    aConfirmedBy: item.a_confirmed_by ?? null,
    aConfirmedAt: item.a_confirmed_at ?? null,
    pConfirmedBy: item.p_confirmed_by ?? null,
    pConfirmedAt: item.p_confirmed_at ?? null,
  }
}

// 状态流转：Pending → Confirmed
// - A Status：Advertiser 确认
// - P Status：Publisher 确认
// - 只有双端确认，才进入最终结算
```

**业务价值**：

- ✅ **100% 杜绝亏本倒挂**：只有广告主确认的数据，才结算给 Publisher
- ✅ **减少资金压力**：避免垫资给未确认的数据
- ✅ **提升信任度**：双端确认，数据透明，建立信任

#### 4.2.2 自动化财务对账

SAAS New 提供**自动化财务对账**功能，减少 80% 人工操作。

**核心功能**：

1. **Upload Statement**（上传对账单）：
   - 支持 .xlsx/.csv 文件上传
   - 自动解析和对齐字段
   - 自动匹配差异（Disc.% 预警）

2. **快速编辑**：
   - Scrub Rev/Scrub/Cover/S Conv/PB Conv/Reason 等字段快速编辑
   - 点击编辑，Enter 保存
   - 支持批量操作

3. **Confirm & Update**：
   - 确认并更新到数据库
   - 并行调用 `updateMonthReport` 接口
   - 支持批量更新

4. **导出 PDF**：
   - 账单预览和导出 PDF
   - 支持自定义模板

**业务价值**：

- ✅ **效率提升**：自动化对账，减少 80% 人工操作
- ✅ **错误率降低**：自动匹配差异，错误率降低 95%+
- ✅ **可追溯**：所有操作记录可追溯，便于审计

#### 4.2.3 异常预警与处理

SAAS New 提供**异常预警与处理**功能，及时发现和处理财务异常。

**核心功能**：

1. **Disc.% 预警**：
   - 自动计算 Discrepancy Rate（差异率）
   - 超过阈值（如 30%），高亮预警
   - 支持原因分类（Fraud、CTIT limit、Post-Attribution 等）

2. **快速调整**：
   - Scrub Revenue/Scrub Payout/Cover 等字段快速调整
   - 支持批量调整
   - 记录调整原因

3. **状态流转**：
   - A Status Confirmed → P Status Pending → P Status Confirmed
   - 支持多选批量操作
   - 状态变更记录可追溯

**业务价值**：

- ✅ **风险可控**：异常预警，及时发现和处理风险
- ✅ **灵活调整**：快速调整，应对各种异常情况
- ✅ **审计友好**：所有操作记录可追溯，便于审计
