```powershell

# 2. 解压到 C:\nginx-1.26.3\
# 3. 测试 Nginx 是否正常工作
```

**集成 CI/CD（可选）**：

```yaml
# .github/workflows/deploy.yml（示例）
name: Deploy to Production

on:
  push:
    branches: [ master ]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '22'
      
      - name: Install dependencies
        run: npm install
      
      - name: Build
        run: npm run build
      
      - name: Deploy to server
        uses: appleboy/scp-action@master
        with:
          host: ${{ secrets.SERVER_IP }}
          username: administrator
          password: ${{ secrets.SERVER_PASSWORD }}
          source: "dist/*"
          target: "C:/saas_new"
      
      - name: Reload Nginx
        uses: appleboy/ssh-action@master
        with:
          host: ${{ secrets.SERVER_IP }}
          username: administrator
          password: ${{ secrets.SERVER_PASSWORD }}
          script: |
            cd C:\nginx-1.26.3
            .\nginx.exe -s reload
```

## 3. 日志管理

### 3.1 日志位置

| 日志类型 | 路径 | 说明 |
|----------|------|------|
| **Nginx 访问日志** | `C:\nginx-1.26.3\logs\access.log` | 所有请求记录 |
| **Nginx 错误日志** | `C:\nginx-1.26.3\logs\error.log` | 错误信息 |
| **应用日志** | 前端无后端日志 | 后端日志在独立服务器 |
| **系统日志** | Windows 事件查看器 | 系统级错误 |

### 3.2 日志轮转（Log Rotation）

**使用 PowerShell 脚本自动清理**：

```powershell
# 创建日志清理脚本（deploy/log-rotation.ps1）
$DaysToKeep = 30
$LogsPath = "C:\nginx-1.26.3\logs"

Get-ChildItem -Path $LogsPath -Filter "*.log" | ForEach-Object {
    if ($_.LastWriteTime -lt (Get-Date).AddDays(-$DaysToKeep)) {
        Write-Host "删除旧日志：$($_.Name)"
        Remove-Item $_.FullName -Force
    }
}

# 添加到计划任务（每天凌晨 3 点执行）
# 打开"任务计划程序" → 创建基本任务 → 触发器：每天 03:00
```

### 3.3 日志分析

**常见问题排查**：


## 5. 故障排查

### 5.1 常见问题

#### 问题 1：网站无法访问

**排查步骤**：

```powershell
# 1. 检查 Nginx 是否运行
Get-Process -Name "nginx" -ErrorAction SilentlyContinue

# 如果未运行，启动 Nginx
cd C:\nginx-1.26.3
.\nginx.exe

# 2. 检查端口是否被占用
netstat -ano | Select-String ":80 "

# 如果端口被占用，找出占用进程
Get-Process -Id (Get-NetTCPConnection -LocalPort 80).OwningProcess

# 3. 检查防火墙规则
Get-NetFirewallRule | Where-Object { $_.DisplayName -like "*Nginx*" }

# 如果未配置，添加防火墙规则
New-NetFirewallRule -DisplayName "Nginx HTTP" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow

# 4. 检查 Nginx 错误日志
Get-Content "C:\nginx-1.26.3\logs\error.log" -Tail 50

# 5. 测试本地访问
Invoke-WebRequest -Uri "http://localhost" -UseBasicParsing
```

#### 问题 2：静态资源 404

**排查步骤**：

```powershell
# 1. 检查文件是否存在
Get-ChildItem -Path "C:\saas_new" -Recurse | Where-Object { $_.Name -like "*.js" }

# 2. 检查 Nginx 配置（root 路径是否正确）
Get-Content "C:\nginx-1.26.3\conf\nginx.conf" | Select-String "root"

# 3. 检查文件权限
icacls "C:\saas_new"

# 如果权限不足，添加权限
icacls "C:\saas_new" /grant "Everyone:(OI)(CI)R"

# 4. 重新加载 Nginx 配置
cd C:\nginx-1.26.3
.\nginx.exe -s reload
```

#### 问题 3：API 代理失败

**排查步骤**：

```powershell
# 1. 检查后端 API 是否可访问
Invoke-WebRequest -Uri "http://saas.melo.support/api/v1/health" -UseBasicParsing

# 2. 检查 Nginx 代理配置
Get-Content "C:\nginx-1.26.3\conf\nginx.conf" | Select-String "proxy_pass"

# 3. 检查 Nginx 错误日志（查看代理错误）
Get-Content "C:\nginx-1.26.3\logs\error.log" -Tail 50 | Select-String "proxy"

# 4. 测试代理是否工作
Invoke-WebRequest -Uri "http://121.43.101.136/api/v1/advertisers" -UseBasicParsing
```

## 6. 性能优化

### 6.1 Nginx 优化

**优化后的 nginx.conf**：

```nginx
# ─── 全局配置 ─────────────────────────────────
worker_processes  auto;  # 自动检测 CPU 核心数
worker_rlimit_nofile 65535;  # 每个 worker 进程最大文件描述符数

events {
    worker_connections  4096;  # 每个 worker 进程的最大连接数
    use epoll;  # Linux 使用 epoll，Windows 自动选择
    multi_accept on;  # 一次接受所有新连接
}

http {
    # ─── 基础优化 ─────────────────────────
    sendfile        on;
    tcp_nopush      on;
    tcp_nodelay     on;
    keepalive_timeout  65;
    keepalive_requests 100;  # 每个 keepalive 连接最大请求数

    # ─── 缓冲区优化 ───────────────────────
    client_body_buffer_size 128k;
    client_max_body_size 10m;
    client_header_buffer_size 1k;
    large_client_header_buffers 4 4k;

    # ─── 超时优化 ─────────────────────────
    client_body_timeout 12;
    client_header_timeout 12;
    send_timeout 10;

    # ─── Gzip 压缩 ───────────────────────
    gzip  on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_buffers 4 32k;
    gzip_comp_level 6;
    gzip_types text/plain text/css text/xml text/javascript application/json application/javascript application/xml+rss application/rss+xml application/atom+xml;

    # ─── 静态资源缓存 ────────────────────
    location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|woff|woff2|ttf|eot)$ {
        expires 365d;
        add_header Cache-Control "public, immutable";
        access_log off;
    }

    # ─── 代理优化 ─────────────────────────
    proxy_connect_timeout 60s;
    proxy_send_timeout 60s;
    proxy_read_timeout 60s;
    proxy_buffering off;
    proxy_buffer_size 4k;
    proxy_buffers 8 4k;
}
```

### 7.2 Windows 安全配置

```powershell
# 1. 禁用不必要的服务
Get-Service | Where-Object { $_.Status -eq "Running" -and $_.Name -notlike "*Nginx*" } | 
    Where-Object { $_.Name -notlike "*SSH*" } | 
    Stop-Service -WhatIf  # 先预览，确认后去掉 -WhatIf

# 2. 配置 Windows 防火墙
# 只允许必要端口：80 (HTTP)、22 (SSH)、3389 (RDP)
New-NetFirewallRule -DisplayName "Allow HTTP" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow
New-NetFirewallRule -DisplayName "Allow SSH" -Direction Inbound -Protocol TCP -LocalPort 22 -Action Allow
New-NetFirewallRule -DisplayName "Allow RDP" -Direction Inbound -Protocol TCP -LocalPort 3389 -Action Allow

# 3. 启用 Windows 更新自动更新
Set-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate\AU" -Name "AUOptions" -Value 4

# 4. 安装安全补丁
Install-Module -Name PSWindowsUpdate
Install-WindowsUpdate -AcceptAll -AutoReboot

# 5. 配置审计策略（记录登录事件）
auditpol /set /subcategory:"Logon" /success:enable /failure:enable
```
