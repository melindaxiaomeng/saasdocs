## 1. 系统概述

本系统是一套广告投放管理平台，支持 Campaign（广告活动）、Partner（渠道商/广告主）的全生命周期管理，以及数据报表、财务对账、日志调试等功能。

**技术栈**：React 18 + Vite + Tailwind CSS + Ant Design 5 + Recharts + ECharts

**访问地址**：`http://10.7.94.230:8000`（内网）／ 生产环境 `http://121.43.101.136`

**角色说明**：

| 角色 | 可访问模块 |
|------|-----------|
| 超级管理员 | 全部模块 |
| 运营人员（BD/PM） | Workplace、Report Center、Resources、Finance、Logs |
| 财务人员 | Finance |
| 开发人员 | Logs & Debug、Tools & Settings |

## 2. Overview（总览）

**路由**：`/overview`

**功能概述**：系统首页，展示当日及近 7 天的核心 KPI 指标，帮助运营人员快速掌握业务动态。

### 主要功能

#### 2.1 核心 KPI 卡片

展示 4 个核心指标卡片，每个卡片包含：
- **当日数值**（大字体）
- **周汇总**（副标题）
- **日环比增长率**（绿色↑ / 红色↓）

| 指标 | 说明 | 计算方式 |
|------|------|---------|
| Revenue（营收） | 当日总收入 | API: `getDailyKPI` |
| Profit（利润） | 当日毛利 | Revenue - Payout，同时显示 Margin 百分比 |
| Clicks（点击） | 当日点击量 | 同时显示 7 天均值 |
| Conversions（转化） | 当日转化数 | 同时显示 CVR（Conversion Rate） |

> **数据来源**：`getDailyKPI` 接口，返回近 7 天每日数据，前端计算增长率。

#### 2.2 7-Day Trend 弹窗

点击任意 KPI 卡片，弹出 **7-Day Trend** 趋势弹窗：
- 支持切换指标（Revenue / Cost / Conversions / Clicks）
- 面积图展示近 7 天趋势
- 日期范围显示在标题下方

#### 2.3 异常预警（Anomaly Warning）

页面顶部显示异常预警条：
- 调取 `getAnomalyWarning` 接口
- 展示异常类型、涉及 Campaign、异常数值
- 点击可跳转至对应页面

#### 2.4 实时 KPI（Realtime KPI）

页面右侧展示实时数据面板：
- 调用 `getRealtimeKPI` 接口
- 展示当前正在进行中的 Campaign 实时数据

#### 2.5 Ranking（排行榜）

调用 `getRanking` 接口，展示：
- Top Advertisers（按 Revenue 排行）
- Top Publishers（按 Revenue 排行）
- Top Campaigns（按 Revenue 排行）

点击排行中的任意条目，可跳转至对应详情页。

## 3. Workplace（工作台）

### 3.1 Campaign Center（广告活动中心）

**路由**：`/workplace/campaign`

**功能概述**：管理所有广告活动（Campaign），支持创建、编辑、批量操作、状态切换等。

#### 主要功能

**3.1.1 Campaign 列表**

表格列字段：

| 列名 | 字段 | 说明 |
|------|------|------|
| ID | `id` | 唯一标识 |
| Campaign | `campaignName` | 活动名称，点击可跳转详情 |
| Advertiser | `advertiserName` | 所属广告主 |
| Status | `status` | Active / Paused / Stopped，带颜色标签 |
| Revenue | `revenue` | 营收，等宽数字字体 |
| Payout | `payout` | 成本 |
| Profit | `profit` | 利润 |
| Margin | `margin` | 利润率百分比 |
| Conversions | `conversions` | 转化数 |
| CVR | `cvr` | 转化率 |
| AM | `am` | 负责 AM（Account Manager） |
| PM | `pm` | 负责 PM（Publisher Manager） |
| Label | `label` | 标签（Hot / Top / New） |
| 操作 | — | 编辑、暂停/启用、更多 |

**3.1.2 快速筛选栏**

- 搜索框：按 Campaign 名称 / ID 搜索
- 状态筛选：All / Active / Paused / Stopped
- 标签筛选：All / Hot / Top / New
- 国家筛选：多选下拉（US / UK / JP / DE / SG / BR / AU）
- 排序：按 Revenue / Clicks / Conversions / ID 降序

**3.1.3 批量操作**

选中多条记录后，底部出现批量操作栏：

| 操作 | 说明 |
|------|------|
| Active / Pause | 批量切换状态（Stopped 状态不可操作） |
| Delete | 批量删除（需二次确认） |
| Add Label | 批量添加标签 |
| Export | 导出选中记录为 CSV |

**3.1.4 创建 Campaign**

点击「+ New Campaign」按钮，弹出创建表单（Drawer 或 Modal），字段包括：
- 基础信息：Campaign Name、Advertiser、Package Name、T-Campaign ID
- 投放设置：Country（多选）、Device（ALL/Android/iPhone）、Daily Cap
- 出价设置：Payout、Margin
- 状态：Active / Paused

**3.1.5 编辑 Campaign**

点击表格中的编辑按钮，打开编辑抽屉，支持修改：
- Campaign 名称
- 投放国家
- 设备类型
- 每日 Cap
- Payout / Margin
- 状态

**3.1.6  publishers 关联**

Campaign 详情页（`/workplace/campaign/publishers`）展示该 Campaign 关联的所有 Publisher，支持：
- 查看各 Publisher 的 Payout、Margin、Cap
- 快速编辑 Margin / Payout
- Block / Unblock Publisher

| Publisher List | 所有渠道商列表 |

| Group List | 渠道商分组管理 |
| Block Campaign | 被 Block 的 Campaign 列表 |
| Block Publisher | 被 Block 的 Publisher 列表 |

#### 3.2.1 Advertiser List

**表格列**：

| 列名 | 字段 | 说明 |

| Margin | `margin` | 利润率 |
| AM | `am` | 负责 AM |
| Contact | `contactEmail` | 联系邮箱 |

**创建/编辑 Advertiser Drawer**，表单字段分组：

#### 3.2.2 Publisher List

**表格列**：

| 列名 | 字段 | 说明 |

**创建/编辑 Publisher Drawer**，表单字段分组：

1. **基础信息**：Publisher Name、Publisher ID、Status
2. **联系信息**：Contact Name、Email、Phone、Skype/Telegram

6. **限额设置**：Monthly Cap、Daily Cap

#### 3.2.4 Group List

- 向分组内添加 Publisher

- 查看 Block 原因、Block 时间、操作人
- 批量 Unblock

#### 3.2.6 Block Publisher

被 Block 的 Publisher 列表，支持：
- 查看 Block 原因、Block 时间、操作人
- 批量 Unblock

#### 3.2.7 Publisher Global Rules

点击 Publisher 行中的「Global Rules」按钮，打开全局规则配置抽屉：

### 3.3 Partner Control（渠道商控制）

**路由**：`/workplace/partner/control`

**功能概述**：对渠道商进行精细化控制，包括流量分配、权重调整、Block/Reject 策略等。

#### 主要功能

**3.3.1 Publisher-Campaign 关系表**

展示所有 Publisher 与 Campaign 的关联关系，表格字段包括：

| 列名 | 字段 | 说明 |
|------|------|------|
| Publisher | `publisherName` | 渠道商名称 |
| Campaign | `campaignName` | 广告活动名称 |
| Margin | `margin` | 当前 Margin |
| Payout | `payout` | 当前 Payout |
| Cap | `cap` | 每日 Cap |
| Weight | `weight` | 流量权重（0-100） |
| Status | `status` | Active / Blocked / Rejected |
| 操作 | — | 编辑、Block、Reject |

**3.3.2 快速编辑**

支持点击单元格快速编辑：
- Margin（直接输入数值，Enter 保存）
- Payout（直接输入数值，Enter 保存）
- Cap（直接输入数值，Enter 保存）
- Weight（直接输入数值，Enter 保存）

**3.3.3 Block / Reject 策略**

- **Block**：暂停该 Publisher 在该 Campaign 上的投放，可填写原因
- **Reject**：彻底拒绝该 Publisher 在该 Campaign 上的投放，需填写原因

**3.3.4 批量操作**

- 批量设置 Margin
- 批量设置 Cap
- 批量 Block
- 批量 Reject

## 4. Report Center（报表中心）

### 4.1 Internal Performance Hub（内部业绩中心）

**路由**：`/report/performance`

**功能概述**：全维度数据报表，支持按多个维度分组、指标自选、图表展示、对比模式、排行榜等。

#### 主要功能

**4.1.1 视图模式**

| 模式 | 说明 |
|------|------|
| Standard（标准） | 全维度报表，支持分组、筛选、图表 |
| Comparison（对比） | 将两个时间段的数据并排对比 |
| Ranking（排行） | 按指定维度展示 Top N 排行 |

**4.1.2 维度分组（Group By）**

支持按以下维度分组展示数据：

| 维度 | 说明 | 支持双维度组合 |
|------|------|---------------|
| Date | 按日期 | ✅（配合 Hour） |
| Hour | 按小时 | ✅（配合 Campaign/Publisher/Country） |
| Advertiser | 按广告主 | ❌（仅单选） |
| Publisher | 按渠道商 | ✅（配合 Campaign/Country/Hour） |
| Campaign | 按广告活动 | ✅（配合 Country/Publisher/Hour） |
| Package | 按包名 | ❌（仅单选） |
| Country | 按国家 | ✅（配合 Campaign/Publisher/Hour） |
| OS | 按操作系统 | ❌（仅单选） |
| Channel | 按渠道 | ❌（仅单选） |
| T-Campaign ID | 按 T 侧 Campaign ID | ❌（仅单选） |

> 双维度组合规则由 `ALLOWED_ALLIES` 常量定义，仅允许白名单内的组合。

**4.1.3 指标选择**

指标分为两类：

**数值型指标**：
- Impressions（展示量）
- Clicks（点击量）
- Conversions（转化数）
- Pb Conv.（Postback 转化数）
- Revenue（营收）
- Payout（成本）
- Profit（利润）
- Avg. Prc.（平均出价）

**比率型指标**：
- CTR（点击率）
- CVR（转化率）
- eCPM（千次展示成本）
- ROI（投资回报率）

用户可自定义显示哪些指标列。

**4.1.4 筛选器**

- 日期范围选择（DateRangePicker）
- Advertiser 多选
- Publisher 多选
- Campaign 多选
- Country 多选
- OS 多选

**4.1.5 图表展示**

- 面积图（AreaChart）：展示趋势
- 柱状图（BarChart）：展示对比
- 组合图（ComposedChart）：同时展示柱状+折线

图表支持点击图例隐藏/显示对应数据系列。

**4.1.6 对比模式（Comparison）**

选择两个时间段（如本周 vs 上周），系统并排展示：
- 绝对数值对比
- 增长率（绿色↑ / 红色↓）
- 图表双 Y 轴对比

**4.1.7 排行榜（Ranking）**

选择维度和指标，展示 Top N 排行：
- 支持设置 N 值（默认 Top 10）
- 支持按 Revenue / Profit / Conversions 等排序
- 展示排名变化（↑↓）

**4.1.8 导出**

- 导出为 CSV
- 导出为 Excel（待开发）
